## 바꾼 것

**검출기(결과 바이트 단위 동일)**

| 위치 | 내용 | 효과 |
|---|---|---|
| ① `carla.py` `edge_like` | 화소 다섯 묶음을 한 번에 모으고 행마다 같은 순서로 합침 | 호출당 16 → 5 µs |
| ② `carla.py` `pair_vote`, 조각 지지 판정 | 반복문 안 numpy 스칼라 대신 파이썬 float | – |
| ③ `carla.py` `clone()` | `dataclasses.replace`와 같은 결과(필드만 복사)를 내는 빠른 복제. 가닥 합치기와 시간 추적에 사용 | – |
| ④ `core.py` `median()` | 32개 이하 배열은 파이썬 정렬(NaN이 섞이면 기존 경로) | 2만 건 비교 동일, 약 2배 빠름 |
| ⑤ `carla.py` `binary()` | 상대 노란색의 `medianBlur`(1.6 ms)를 다른 스레드에서 돌리는 동안 능선 계산 | – |
| ⑥ `temporal.py` | 선 종류 기록 마스크 7장을 4채널로 묶어 옮김(최근접 보간이라 채널별 동일) | 0.63 → 0.32 ms |
| ⑦ `temporal.py` | 조각 위치 다듬기의 겹침 구간을 같은 원소의 슬라이스로 | – |
| ⑧ `carla.py` `merge_strands` | 가닥별 보간·자르기를 이어 붙여 한 번에(요소별 연산) | – |
| ⑨ `carla.py`/`temporal.py` | 같은 BEV의 회색조 변환을 한 번만 | – |

- ⑤⑥은 `carla_parallel_ops`(코드 기본 false, carla.yaml true)로 켠다.
- 오프라인 검출기 시간(maploop 5–15 s): 18.1 → 17.3 ms. 파이썬 호출 비용이 여러 곳에 흩어져 있어 미세 조정의 효과는 작았다.

**구조(결과 동일)**

| 설정 | 내용 |
|---|---|
| `display_filter_in_worker` | 표시 필터를 검출 계산 프로세스에서 돌린다. 메인 프로세스에서는 ROS 스레드와 GIL을 다투어 오프라인 1.15 ms가 실시간 3.5 ms(p95 9 ms)였다. 표시 필터 단계를 계산(`DisplayCore`)과 메시지 만들기(`DisplayStage.messages`)로 나눴다 |
| `display_publish_in_worker` | 표시선 토픽을 계산 프로세스가 직접 발행한다 |
| `image_in_worker` | 계산 프로세스가 카메라와 위치(odom) 토픽을 직접 구독한다(깊이 1 = 최신 1장). 6 MB 영상 복사, 프로세스 사이 주고받기, 메인 프로세스의 GIL 대기가 표시선 경로에서 빠진다(평균 1.7 ms, p95 3–4 ms + 콜백 지연) |

- 세 설정 모두 코드 기본 false, carla.yaml true다.
- `image_in_worker`에서는 계산 프로세스가 5 Hz로 겹쳐 그리기 크기(960 폭)의 영상을 노드에 보내 디버그 이미지를 그린다. 노드는 받은 결과로 나머지 토픽(칠, 스타일, 경계, 선분, 노면 표시)을 낸다.
- 학습 거르기(`learned_weights`)를 켜면 `image_in_worker`는 쓰지 않고 이전 방식으로 돈다.
- 실행 스크립트 `run_lane_hud.sh`는 그대로 쓰면 된다(carla.yaml을 따른다).

**동일성 확인**

## 확인하지 못한 것, 남은 것

- 검출 자체의 무거운 구간 평균 15 ms 이하는 못 채웠다(15.1–18.9 ms). 더 줄이려면 검출기 핵심을 네이티브 코드로 옮겨야 한다. 이때 `polyfit` 같은 LAPACK 계산 결과를 비트까지 같게 유지하기 어렵다.
- 원격 화면(NoMachine) 같은 다른 부하가 있으면 기준을 넘는다. 실제 사용 환경의 부하에서는 다시 재야 한다.
- 실행 중 사용자가 "차선 변화가 너무 심하게 발생한다"고 했다. 이번 변경은 검출 결과와 표시선을 바꾸지 않았으므로(프레임별로 동일), 그 현상은 이번 변경 전부터 있던 동작이다. 어느 영상·시점인지 아직 확인하지 못했다.
- HUD 프로세스 안의 수신 시각은 HUD를 고치지 않아 재지 않았다(같은 토픽을 구독한 측정 프로세스 값).
- 살아 있는 CARLA 연결은 확인하지 못했다(설치돼 있지 않음).
