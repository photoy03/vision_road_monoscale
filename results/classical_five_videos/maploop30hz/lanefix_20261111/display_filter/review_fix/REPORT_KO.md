## 계획에서 바꾼 점

- **재시작 판정에 0.5초 여유를 뒀다.** 선 종류는 별도 토픽이라 경계보다 한두 프레임 늦게 올 수 있다. "조금이라도 뒤로 가면 초기화"로 하면 정상 재생 중에도 초기화된다. 0.5초 이내로 뒤로 간 경계 메시지는 늦게 온 것으로 보고 버린다.
- **1€ 속도 상태(dx).** 이동할 때 그대로 둠, 매번 0, 매번 절반을 비교했다. 차이는 0.02 cm, 0.02 m 안쪽이다. 커브 지연 p95가 가장 낮은 "그대로 둠"을 택했다.

| dx 처리 | 직선 떨림 L/R (cm) | 커브 지연 p95 L/R (m) |
|---|---|---|
| 그대로 둠 | 0.43 / 0.36 | 0.051 / 0.059 |
| 매번 0 | 0.41 / 0.35 | 0.054 / 0.076 |
| 매번 절반 | 0.42 / 0.35 | 0.053 / 0.072 |

- **1€ 범위 재시험.** 이동 보정을 켜고 녹화 입력으로 다시 실행했다.

| min_cutoff / beta | 직선 L/R (cm) | 전체 L/R (cm) | 지연 p95 L/R (m) |
|---|---|---|---|
| 0.3 / 1.0 (이전) | 0.43 / 0.36 | 0.55 / 1.48 | 0.051 / 0.059 |
| **0.3 / 0.5 (최종)** | 0.41 / 0.29 | 0.49 / 1.24 | 0.052 / 0.058 |
| 0.1 / 0.5 | 0.40 / 0.25 | 0.45 / 1.03 | 0.056 / 0.066 |
| 1.0 / 1.0 | 0.48 / 0.52 | 0.67 / 1.78 | 0.045 / 0.065 |

## 검증 (실제 ROS, 같은 실행 안에서 30 Hz 재생 2회, 각 1807/1807 메시지)

| 항목 | 수정 전 (`ros_run2`) | 수정 후 1회차 | 수정 후 2회차 |
|---|---|---|---|
| 실측 색인데 원본과 0.30 m 넘게 다른 프레임 (L/R) | 0 / 8 | **0 / 0** | 0 / 0 |
| 직선 떨림 (cm, 원본 0.82/1.02) | 0.47 / 0.36 | **0.41 / 0.29** | 0.41 / 0.29 |
| 켜짐 횟수 (원본 18/61) | 4 / 4 | **4 / 4** | 4 / 4 |
| 커브 지연 평균 (m) | 0.039 / 0.045 | **0.024 / 0.024** | 0.024 / 0.024 |
| 커브 지연 p95 (m) | 0.085 / 0.078 | 0.052 / 0.058 | 0.052 / 0.058 |
| 재관측 순간 차이, 5프레임 이상 유지 후 (m) | L 0.945 (1건), R 0.428 (2건) | L 없음, **R 0.090** (2건) | 같음 |

- **2회차 재생.** 1회차와 수치가 같다. 재시작 뒤에도 정상으로 갱신된다. 수정 전 코드라면 2회차에는 시각이 뒤로 가서 갱신이 멈춘다.
- **비교 지점.** 원본 관측이 10 m를 덮지 않는 프레임(10.7–11.9 m에서 시작하거나 10 m 전에 끝남)은 관측 구간에서 10 m에 가장 가까운 점에서 비교했다.
- **재관측 사례.** 실제로는 몇 건뿐이라, 같은 녹화에서 3초마다 0.5초씩 관측을 일부러 지워 비교했다(`dropout_0.5s.txt`).

| 0.5초 유지가 끝날 때 10 m 오차 | 왼쪽 평균 / p95 | 오른쪽 평균 / p95 |
|---|---|---|
| 이동 보정 없음 (이전 동작) | 0.100 / 0.385 m | 0.168 / 0.505 m |
| 이동 보정 | **0.015 / 0.035 m** | **0.031 / 0.128 m** |

- **0.9초 유지일 때.** 같은 방법으로 쟀을 때 이동 보정 없음은 0.129/0.101 m, 이동 보정은 0.018/0.028 m다.
- **표시 프레임 수.** 왼쪽은 1316 → 1251이다. 유지 중 차가 전진하면 그리는 끝도 그만큼 줄어, 10 m에 못 미치는 프레임이 생기기 때문이다. 예전에 표시되던 프레임은 지금도 모두 표시된다.
- **오도메트리가 없는 프레임.** 영상 끝 3개뿐이다.

## 남은 한계

- **원본과의 비교일 뿐이다.** 모든 수치는 검출기 원본과 비교한 것이고, 차선의 실제 위치와 비교한 평가가 아니다.
- **기준 자세의 정확도.** 이동 보정은 `/road/reference_odom`(CARLA 기록 자세)을 쓴다. 실차 오도메트리라면 그 오차만큼 유지선이 어긋난다.
- **재관측 사례가 적다.** 실제 재관측은 오른쪽 14건이고, 그중 1.64 m짜리 1건은 유지하던 선과 다른 선이 잡힌 경우다. 이동 보정과는 무관하다.
