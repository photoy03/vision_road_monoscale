# 계획 32 4회차 — 끝 자르기가 선을 굶긴 것 바로잡기

날짜: 2026-11-20.

- 기준: `round_03`.
- 새 지표 `../jcoverage.py`(`coverage.md`): 정답 내 차로 선이 칠해진 프레임 중, 15 m 에서 표시선이 보이는 비율과 정답에서 30 cm 안인 비율, 벗어난 비율.
  - 제외는 A1 과 같다.
  - 흔들림을 줄이느라 선을 덜 보여 주면 여기서 드러난다.

## 찾은 것 (1–3회차의 회귀)

s5 전후 비교 그림을 만들다가 고친 뒤 영상에서 9–12 초에 선이 18 m 까지 안 닿는 프레임이 많은 것을 보았다. `coverage.md` 로 재 보니 1회차(끝 자르기)부터 순환도로 장면에서 맞는 선을 보여 주는 비율이 줄었다.

| 영상 | 15 m 맞는 선 % (0회차 → 1–3회차) |
|---|---|
| s3a | 79.9 → 65.9 |
| s5 | 94.8 → 88.5 |
| s8c | 95.0 → 90.6 |
| s8d | 92.7 → 87.6 |
| s8b | 87.1 → 82.4 |
| s1 | 91.5 → 89.5 |

- 원인: 유지하는 선이 늦는 곳(지그재그·차로 변경)에서는 관측이 8–10 m 에서 0.15 m 넘게 벗어난다. 그래서 자르고 남은 부분이 3 m(`update_span_m`)보다 짧아져 버려진다.
- 그 결과 선이 유지만 되다가 사라지거나 짧게 그려졌다.
- 정답 지표(A1–A5)는 검출선을 보므로 이것을 잡지 못했다. 떨림 지표는 선이 있는 프레임만 보므로 오히려 좋아 보였다.

## 바꾼 것

`trim_keep_m: 3.0` 이다. 새 설정이고 코드 기본 0 = 끔이다. `carla.yaml lane_display_filter` 에서 켠다.

- 자르면 3 m 보다 짧아지는 관측은 자르지 않고 통째로 쓴다(끝 자르기 전과 같다).
- 시험: `tests/test_display_filter.py::test_trim_keep_leaves_an_observation_whole_when_the_cut_would_starve_the_line`.
