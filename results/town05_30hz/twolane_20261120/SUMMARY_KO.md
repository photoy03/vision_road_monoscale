# 계획 33 — 차로를 옮길 때만 차로 두 칸, 요약

날짜: 2026-11-20.

- 사용자 요청: 차로를 옮길 때 옮겨 갈 차로까지 두 칸이 보이게 한다. 비틀거림·직진 때는 빼고.
- 자세한 내용: `round_01/REPORT_KO.md`.
- 표: `round_01/twolane.md`.
- 실현 가능성 모의: `twolane_sim.py`.

## 한 일

`lane_display_filter` 의 `two_lane_hold_s: 1.0` 이다(코드 기본 꺼짐, `carla.yaml` 에서 켬).

- 옆 차로 바깥 선을 같은 표시 필터로 따라간다.
- 안내가 `change` 인 동안과 그 뒤 1 초(`return` 이면 바로 끝) 동안, 넘는 선 쪽 바깥 선을 세 번째 선으로 낸다. 위치로 고르고, 차로 폭만큼 떨어진 것만 낸다.
- 인식 작업 프로세스가 `/road/lane_display_outer` 로 낸다(표시선 지연 경로 밖).
- HUD 사본이 그 선을 그린다(원본 HUD 는 그대로).

## 결과

| 지표 | 값 |
|---|---|
| 잘못 켜짐: 직진·비틀거림·차로 안 지그재그(town05, s2, s3b, s6, s7, maploop) | 0 % |
| 잘못 켜짐: 차로 변경에서 4 초 넘게 떨어진 곳(모든 영상) | 0 % |
| ±2 초 밖(넘은 뒤 2–4 초 포함) | s3a 7.5, s4 5.3, s5 1.8, s8c 1.5, s8d 0.6, 나머지 0 % |
| 보인 세 번째 선이 정답 30 cm 안 | 86.6 % (s8d) – 100 % |
| 변경 구간(±2 초)에서 세 줄이 보인 비율 | 8 % (s8c) – 35 % (s3a) |
| 켜지는 시각 | 선을 넘기 0.2–0.5 초 전 (s3a·s4 의 잦은 넘나듦은 3 초 전부터) |
| 계획 32 지표(흔들림·맞는 선 비율), 정답 지표 A–C | 바뀌지 않음(내 차로 표시선 동일) |
| 지연 가운데(town05 × 3) | 신호 켬 25.47, 끔 23.92 ms |

- 세 줄 비율이 낮은 이유는 두 가지다.
  - `change` 가 넘기 직전에야 켜진다. 일찍 켜는 후보 둘은 s2·s3b 에서 13–59 % 잘못 켜져 버렸다.
  - 그 순간 바깥 선이 검출되지 않는 일이 많다(s8c 순환도로).
- 바깥 선이 없을 때 내 차로 선을 차로 폭만큼 옮겨 그리는 것은 틀린 선이 많아(s4 33 %, s8c 79 % 만 30 cm 안) 하지 않았다.
